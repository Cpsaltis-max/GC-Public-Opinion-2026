FRESH GITHUB PAGES UPLOAD — GC PUBLIC OPINION 2026

1. Create a new PUBLIC GitHub repository.
2. Choose “uploading an existing file”.
3. Open this folder and upload its CONTENTS—not the enclosing folder.
   The repository root must contain index.html, .nojekyll, assets, and downloads.
4. Commit the upload directly to the main branch.
5. Open Settings > Pages.
6. Under “Build and deployment”, select:
      Source: Deploy from a branch
      Branch: main
      Folder: / (root)
7. Click Save and wait for the Pages deployment to finish.

Important: keep the filenames and folder structure exactly as supplied.
The site uses relative paths and therefore works under any GitHub Pages
repository name.
